| Attribute | Details |
|:--|:--|
| **Stack** | Java · J2EE · Spring Boot 2.7 · JSP · JSTL · Spring Data JPA · Oracle · Docker |
| **Deployment** | Docker container · Render |
| **Customer features** | Registration/login, hotel & resort browsing by city, date-based room availability, booking management |
| **Room & cart flow** | Single / Double / Deluxe rooms → add to cart → remove or checkout |

* Full documentation: ERD, DFD, use-case diagrams, Function Point cost analysis, SDLC
